# STM32 步进电机控制器

完整工程源码已按轴明确分开，包含头文件、源文件、CubeMX 配置和 Keil 工程。

## 工程

- `X_axis_controller/`：X轴最终控制器，控制两个步进电机和一个光电传感器。
- `Y_axis_controller/`：Y轴最终控制器，控制一个步进电机和两个限位传感器。

打开工程：

- `X_axis_controller/MDK-ARM/bjdj.uvprojx`
- `Y_axis_controller/MDK-ARM/bjdj.uvprojx`

两套程序支持 DM542 的 STEP/DIR 控制、USB CDC 虚拟串口、二进制帧协议和 CRC-8 校验。X轴支持双电机同步运动；Y轴支持两个传感器查询和状态变化自动上报。

X轴功能：
- 控制两个步进电机，适配两个DM542。
- X轴两个电机分别使用STEP/DIR控制。
- 支持USB虚拟串口通信，也保留USART1串口调试。
- 支持正转、反转、停止、状态查询。
- 支持双轴同步运动。
- 最大速度参数为40000脉冲/秒。
- 支持二进制帧协议和CRC校验。
- PA4连接X轴光电传感器。
- 传感器检测到目标时返回状态数据。
引脚：
- 电机1：PA0 = STEP，PA1 = DIR
- 电机2：PA2 = STEP，PA3 = DIR
- X轴传感器：PA4
- USB虚拟串口：USB-C接口
- 旧式串口：PA9 = TX，PA10 = RX

- Y轴功能：
- 控制一个Y轴步进电机和DM542。
- 支持USB虚拟串口通信。
- 支持正转、反转、停止、状态查询。
- 最大速度为40000脉冲/秒。
- PA4、PA5连接两个限位传感器。
- 传感器为低电平有效。
- 支持查询传感器状态。
- 传感器状态发生变化时，自动向上位机发送反馈，不需要一直查询。
引脚：
- Y轴电机：PA0 = STEP，PA1 = DIR
- Y轴传感器1：PA4
- Y轴传感器2：PA5
- USB虚拟串口：USB-C接口
- 旧式串口：PA9 = TX，PA10 = RX
通信协议
数据格式：
AA 55 CMD LEN DATA CRC
- AA 55：帧头
- CMD：命令
- LEN：数据长度
- DATA：参数
- CRC：CRC-8校验，计算多项式为0x07
主要命令：
- 0x10：查询设备信息
- 0x11：控制指定电机运动
- 0x12：停止电机
- 0x13：查询运动状态
- 0x14：双轴同步运动
- 0x15：查询传感器状态
- 0x80：设备信息返回
- 0x81：电机状态返回
- 0x82：传感器状态返回
